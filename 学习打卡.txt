正则
必会的元字符（10个以内）
元字符	含义	例子
.	匹配任意单个字符	a.c 匹配 abc, a c
*	前一个字符出现0次或多次	ab*c 匹配 ac, abc, abbc
+	前一个字符出现1次或多次	ab+c 匹配 abc, abbc，不匹配 ac
?	前一个字符出现0次或1次	ab?c 匹配 ac, abc
[]	匹配括号中的任意一个字符	[0-9] 匹配数字，[a-zA-Z] 匹配字母
[^]	反向匹配，不包含括号内的字符	[^0-9] 匹配非数字
^	匹配行开头	^Error 匹配以 Error 开头的行
$	匹配行结尾	done$ 匹配以 done 结尾的行
|	或	error|fail 匹配包含 error 或 fail 的行
()	分组	(abc){2} 匹配 abcabc
\	转义	\. 匹配点号本身

实验过程疑问，怎么知道我的程序是否安装好了
	主程序文件：通常在 /usr/bin/ 或 /usr/sbin/ 目录下，文件名一般和包名相同。可以使用 which nginx 或 whereis nginx 来定位。
	配置文件：常见位置是 /etc/ 目录下，文件名通常是 包名.conf 或同名的目录。例如 nginx 的配置文件一般是 /etc/nginx/nginx.conf，而 httpd 的是 /etc/httpd/conf/httpd.conf。
	日志文件：通常在 /var/log/ 目录下有一个和包名同名的目录，比如 /var/log/nginx/
